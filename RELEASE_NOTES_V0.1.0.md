# Youtube Studio 0.1.0

The first Windows release is designed around a quick path: **find media, choose an offered format, and let Downloads handle the rest**.

- Search by name or paste a public video, Short, playlist, or channel link.
- Pick individual videos or a batch, with video quality or audio choices.
- See measured progress, pause/retry work, and recover unfinished downloads after restart.
- Play verified local media in Library and batch convert files while keeping originals.
- Use a branded installer with the Youtube Studio logo and a separate portable build.

![Youtube Studio Home](images/home.png)

**Release status:** This is a prepared release brief. No installer or portable file is public yet. The bundled FFmpeg runtime's redistribution materials and physical failure tests must be completed first. Windows packages are intentionally unsigned. Public media availability and offered formats can change.
